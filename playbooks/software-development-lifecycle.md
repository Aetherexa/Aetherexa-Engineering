# Software Development Lifecycle

## Stages

1. Discover: PRD, constraints, and success metrics
2. Design: RFC, ADRs, threat model, test strategy
3. Build: implementation with progressive validation
4. Verify: QA, performance, accessibility, security review
5. Release: staged rollout, observability, rollback readiness
6. Operate: incidents, support loops, reliability improvements
7. Evolve: retrospectives, debt repayment, roadmap update

## Mandatory Artifacts

- PRD
- RFC for non-trivial changes
- ADR for architecture-impacting decisions
- Test plan and coverage report
- Release notes and rollback plan
