# Developer Workflow

1. Pick or create issue with clear acceptance criteria.
2. Read PRD, RFC, ADR, and related issues.
3. Create short-lived branch.
4. Implement with tests and docs updates.
5. Run local quality suite.
6. Open PR with complete checklist.
7. Address review feedback quickly.
8. Merge after all gates pass.
9. Validate post-merge telemetry when production impact exists.
