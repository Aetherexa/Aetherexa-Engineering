# Engineering Metrics System

## Delivery Metrics

- Lead time for change
- Deployment frequency
- Change failure rate
- Mean time to recovery

## Quality Metrics

- Escaped defects
- Defect reopen rate
- Flaky test rate
- Coverage trend for critical paths

## Reliability Metrics

- Availability against SLO
- Error budget burn rate
- Incident count by severity

## Security Metrics

- Time to triage vulnerabilities
- Time to remediate critical issues
- Secrets exposure incidents

## Developer Experience Metrics

- Time to first successful build
- CI duration and stability
- PR review turnaround time

## Product Engineering Metrics

- Feature adoption
- Performance percentile goals
- Accessibility conformance

## Usage Rules

- Metrics are for system improvement, not individual punishment.
- Every metric must have owner and response playbook.
