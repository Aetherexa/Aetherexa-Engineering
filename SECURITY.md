# Security Policy

## Scope

This policy applies to all Aetherexa repositories, products, SDKs, CLIs, services, and documentation artifacts.

## Reporting A Vulnerability

- Email: security@aetherexa.com
- Include reproduction steps, impact, and affected versions
- Do not publicly disclose before coordinated remediation

## Response Targets

- Acknowledge report: within 24 hours
- Initial triage: within 72 hours
- Mitigation plan: within 7 days

## Disclosure Policy

Coordinated disclosure is required. CVEs are filed for qualifying vulnerabilities.

## Secure Development Requirements

- Threat model for new high-risk features
- Secrets scanning enabled
- Dependency and SAST scanning enabled
- Security review for auth, data, and network changes
